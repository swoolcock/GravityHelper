# Strict No-AI Policy

## 1. Policy

**The use of artificial intelligence (AI) is strictly prohibited in any activity related to this repository.**

This repository must be developed, maintained, reviewed, and documented entirely by humans without the assistance of generative AI, machine learning-based coding assistants, or autonomous AI agents.

This prohibition applies to all contributors, maintainers, reviewers, contractors, and automated development workflows.

There are no exceptions unless explicitly authorised by the repository owner in writing.

## 2. Prohibited AI Usage

The following activities are strictly prohibited:

- **Code generation:** Using AI to generate, write, complete, modify, refactor, or optimise source code.
- **Code assistance:** Using AI-powered autocomplete, suggestions, inline completions, or coding assistants.
- **Code review:** Using AI to review, analyse, audit, explain, or suggest changes to code.
- **Debugging:** Using AI to diagnose errors, investigate bugs, troubleshoot issues, or propose fixes.
- **Testing:** Using AI to generate, modify, execute, or analyse tests and test results.
- **Documentation:** Using AI to write, rewrite, summarise, translate, or modify documentation, comments, specifications, or README files.
- **Architecture and design:** Using AI to propose, evaluate, or implement software architecture, design decisions, or technical solutions.
- **Research:** Using AI to research technologies, libraries, dependencies, implementation approaches, or technical problems related to this repository.
- **Version control:** Using AI to generate commit messages, pull request descriptions, issue reports, changelogs, or release notes.
- **Agentic workflows:** Allowing AI agents to independently or interactively access, inspect, modify, execute, or manage repository contents.
- **AI-mediated contributions:** Submitting any repository contribution containing work generated or materially influenced by AI.

## 3. Prohibited Tools and Services

The prohibition includes, but is not limited to:

- ChatGPT and OpenAI coding tools.
- GitHub Copilot.
- Claude and Claude Code.
- Google Gemini and Gemini Code Assist.
- Cursor.
- Windsurf.
- Amazon Q Developer.
- Tabnine.
- Replit AI.
- Codeium.
- Continue.
- Aider.
- Autonomous coding agents and AI-powered development bots.
- Any other generative AI or machine-learning-based development assistant.

Renaming, wrapping, integrating, or accessing these tools through third-party software does not make their use permissible.

## 4. Human Authorship Requirement

All contributions must be independently produced by humans.

Contributors must:

1. Personally understand the code they submit.
2. Write and maintain their own code.
3. Independently investigate and resolve technical problems.
4. Write their own documentation and tests.
5. Personally conduct code reviews.
6. Take full responsibility for all submitted changes.

Copying AI-generated output into the repository is prohibited, even if it is subsequently modified, reviewed, or rewritten by a human.

## 5. Automated Tooling

Conventional non-AI development tools are permitted, including:

- Compilers and interpreters.
- Linters and formatters.
- Static analysis tools.
- Conventional test runners.
- Build systems.
- Dependency managers.
- Traditional IDE features that do not rely on AI.
- Conventional CI/CD pipelines.

However, any AI-powered functionality within these tools must remain disabled.

Automated systems must not introduce AI-generated or AI-modified content into the repository.

## 6. Contribution Compliance

By submitting a commit, pull request, patch, or other contribution, contributors affirm that:

- The submitted work was produced without AI assistance.
- No prohibited AI tools or services were used during its creation.
- The contributor has personally verified and understands the submitted changes.
- The contribution complies with this policy.

Maintainers may request clarification or an attestation of human authorship where there are reasonable grounds for concern.

## 7. Violations

Any contribution found to violate this policy may be:

- Rejected without merging.
- Removed or reverted.
- Flagged for further review.
- Excluded from future contributions, subject to repository governance.

Suspected violations should be reported to the repository maintainers.

## 8. Scope and Enforcement

This policy applies to the entire repository, including:

- All branches and commits.
- Source code and configuration files.
- Tests and test fixtures.
- Documentation and supporting materials.
- Build scripts and development tooling.
- Issues, pull requests, and code reviews.
- Generated and vendored repository content.

Where additional `AGENTS.md` files or contributor instructions exist in subdirectories, they must not weaken or override this policy.

## 9. Governing Principle

**Human-only development. No AI-generated content. No AI-assisted development. No AI agents.**

Every contribution to this repository must be the product of human work and independent human judgment.

When in doubt, do not use AI.
